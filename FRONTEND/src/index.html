InSoLiTo is a graph-based network of the co-usage of research software from the tools collection hosted by OpenEBench.

Co-usage is understood as being cited in the same cientific publications.

Search your favourite research software to see how it relates with the other tools inside the community. If you search by topic, it will display the software related to the given branch in bioinformatics.

InSoLiTo First Steps

1st Step

The first step you want to take is to search for a tool in the search bar, for example "trimAl". Have in mind that you have to click on the tool in order to see the graph.

2nd Step

After the graph appears, you can see the tools that are related to the one you have selected. But they are moving like crazy, to solve this problem, you have to click on the "Stabilize" button.

3rd Step

After the graph stabilizes, you can see the tools that are related to the one you have selected. And you can start putting filters on it. Or you can search another tool to display the graph of the two tools together.

4th Step

Once you finish reviewing the graph, you can click on the "Reset" button to start again and view some other graphs.
